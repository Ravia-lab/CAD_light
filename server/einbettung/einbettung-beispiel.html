Schreibweg

Der Rückweg: RaVia schreibt Fachdaten zurück — Solltemperaturen, Luftwechsel, U-Werte, gerechnete Norm-Heizlasten. Geometrie ist ausgenommen und wird mit Begründung abgelehnt, nicht still übergangen. Jeder Schreibvorgang ist im Editor ein Schritt der Rückgängig-Kette: Strg+Z nimmt ihn zurück.

So funktioniert es

const cad = document.querySelector('iframe').contentWindow;

cad.postMessage({
  channel: 'ravia-cad',
  type: 'getExport',
  id: 1,
}, '*');

// Zurückschreiben — 'source' ist Pflicht und landet in der Spur am Modell.
cad.postMessage({
  channel: 'ravia-cad',
  type: 'applyPatch',
  id: 2,
  payload: {
    source: 'RaVia 3.2',
    rooms: [{ id: 'room-eg-0', setpointTemperature: 22 }],
  },
}, '*');

window.addEventListener('message', (e) => {
  if (e.data?.channel !== 'ravia-cad') return;
  // e.data.type    'export' | 'summary' | 'changed' | 'patchApplied' | …
  // e.data.payload die Nutzdaten
});

Was schreibbar ist, sagt getWritableFields — mit Einheit und zulässigem Bereich je Feld. Ausprobieren muss die Gegenstelle nichts.
